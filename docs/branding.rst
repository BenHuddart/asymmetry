Logo and artwork
================

The Asymmetry mark combines a red A and damped wave with a blue time axis.
Use the vector artwork for documents and presentations so its curves remain
sharp at any size.

.. image:: /_static/logo.svg
   :alt: Asymmetry: a red A flowing into a damped wave over a blue time axis.
   :width: 280px
   :class: brand-logo

:download:`Download the SVG master </_static/logo.svg>`.

Colours and proportions
-----------------------

The artwork uses bright red ``#E60007`` and blue ``#1F4D8A`` in the sRGB colour
space. The blue matches the application accent. The branding red is brighter
than the muted red used for fit-series controls.

Keep the mark's proportions and the clear space supplied in the SVG. Its
background and the opening in the A are transparent. On dark backgrounds,
place the full mark on a white backing so the blue axis remains visible.

Application icons
-----------------

Windows uses the mark on a transparent square. macOS uses the same mark on a
light rounded-square tile. Both preserve the original proportions. Small
renditions through 32 pixels strengthen the blue axis, arrowhead, and wave
details while keeping the large A unchanged. The browser favicon uses a
light tile for visibility in light and dark browser themes.

The startup screen displays the full mark with **Asymmetry** and
**Loading analysis tools...**.
